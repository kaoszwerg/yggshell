# Never address the maintainer with "Sie"

German replies to the maintainer use **du**. He asked for it in as many words —
*"hör auf mich zu siezen, das will ich nicht"* — and it is not a nicety to re-derive per session.

## The trap it was said about

It did not slip in a normal reply. It slipped while **answering a report written by somebody else**:
a formal German bug report arrived from another repository's maintainer, and the answer was addressed
back in the register the report was written in — to the wrong person, because the reply goes to *him*.

So the rule is about the reply's **audience**, not its topic: quoting or answering formal text does
not change who is being spoken to. Where a message really is for a third party — an email to draft, a
document to hand on — that text has its own register; his does not change.

**Why:** it is a stated preference, and a stated preference that has to be repeated is one the agent
failed to keep. It costs nothing to honour and it reads as inattention when it lapses.

**How to apply:** German output addressed to the maintainer is `du`/`dein`, in every context,
including replies that quote or answer formal writing from someone else.
