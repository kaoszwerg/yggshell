# Bundled font

**MesloLGS NF** — Apache License 2.0, © 2009–2013 André Berg, patched with Nerd Font glyphs.
The full licence is in `LICENSE-MesloLGS-NF.txt`, as that licence requires.

It is here because it is the font [powerlevel10k](https://github.com/romkatv/powerlevel10k) itself
recommends, and a Powerline prompt in a font without the glyphs is a row of empty boxes — a problem
the user cannot diagnose from inside the terminal that is showing it. Shipping it means a working
prompt with no download and no instructions.

**Only one font is bundled, deliberately.** Four weights come to about 10 MB; a second Nerd Font
family would double that for a difference in taste rather than in capability. Anything else installed
on the machine is offered in the picker, and a name that is not in the list can still be typed in.
